# FitLog

FitLog is a modern, dark-themed fitness and workout routine tracker built with Next.js (App Router) and React Context. It enables users to explore exercises, organize their daily routine, and maintain a bookmark collection for upcoming training sessions.

---

## Technologies Used
- **Framework:** Next.js (App Router)
- **State Management:** React Context API
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Toast Message:** React Toastify

---

## Key Features of the Project
- **Interactive Workout Library:** Browse exercises with visuals, equipment tags, and quick actions directly from the home page.
- **Dynamic Workout Details:** Click any workout to view comprehensive exercise guides and target muscle breakdowns.
- **Seamless Navigation:** Responsive navbar for quick switching between library, daily plans, and saved items.
- **Workout Planning & Management:** Add and manage selected exercises in Today's Plan.
- **Save For Later:** Bookmark exercises to organize future training sessions.
- **Dynamic Stats Calculation:** Real-time updates for total exercises, minutes, and calories based on the active tab.
- **Smart Sorting:** Sort workouts instantly by duration, calories burned, or rating.
- **Interactive Card Actions:** Mark exercises as done, remove items in one click, and receive toast notifications.
- **Loading & Responsive UI:** Polished loading feedback and mobile-optimized layouts across all screens.
